Учимся программировать на **JavaScript** — языке, на котором работают сайты, серверы (Node.js) и
автоматизация рутины. Каждая тема идёт с живой песочницей и задачами, которые проверяются
автоматически прямо в браузере — пишешь код, жмёшь «Проверить» и сразу видишь, где ошибка.

## Кем работать и сколько платят

Код + SQL + понимание данных — самое универсальное комбо на рынке труда:

| Профессия | Чем занимается | Ориентир ЗП в Бишкеке |
| --- | --- | --- |
| Аналитик данных (SQL + скрипты) | выгрузки, отчёты, дашборды для бизнеса | 50 000–100 000 сом |
| QA-инженер / автоматизатор | тестирует продукты, пишет автотесты | 40 000–90 000 сом |
| Джуниор JS/Node-разработчик | фичи для сайтов и серверов | 50 000–100 000 сом |
| Бэкенд-разработчик (с опытом) | API, базы, архитектура сервисов | 150 000–350 000 сом |

<Callout title="Про цифры честно">
Вилки — ориентир по вакансиям Бишкека (hh.kg, телеграм-каналы) на осень 2026; смотрите свежие
объявления перед решениями. Удалёнка на зарубежные команды поднимает вилку в 2–4 раза — а код
на собеседовании везде спрашивают одинаковый.
</Callout>
