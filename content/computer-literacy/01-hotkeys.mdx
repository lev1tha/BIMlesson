## Введение

Каждый раз, когда рука тянется к мыши, чтобы нажать «Правка → Копировать», уходит секунда-две.
За день таких движений сотни, за год — часы чистого времени. **Горячие клавиши** — это команды
компьютеру напрямую с клавиатуры. Разница между «умею копировать» и «работаю не глядя на мышь» —
как между печатью двумя пальцами и слепым методом: тот же человек, вдвое больше сделанной работы.

<BusinessNote>
Посчитаем честно. Сотрудник со знанием двух десятков сочетаний экономит 20–30 минут в день на
копипасте, переключениях и поиске. Это 8–12 рабочих дней в год. На отдел из 20 человек — почти
год рабочего времени одного сотрудника, бесплатно. Именно поэтому в некоторых компаниях базовые
сочетания входят в онбординг наравне с почтой и пропуском.
</BusinessNote>

**Что вы узнаете:**

- как перенести любое сочетание с Windows на macOS по одному простому правилу
- какие базовые сочетания работают в любой программе: копирование, отмена, поиск, печать
- как мгновенно переключать раскладку, окна и рабочие столы, не касаясь мыши
- как делать скриншоты и двигаться по тексту, браузеру и таблицам со скоростью мысли
- как выучить сочетания и не бросить на полпути
- в каких ситуациях привычные сочетания подводят

## Две системы — две клавиши-модификатора

Все сочетания строятся вокруг **клавиш-модификаторов** — они зажимаются первыми и держатся:

| Клавиша | Windows | macOS |
| --- | --- | --- |
| Главный модификатор | **Ctrl** | **Cmd ⌘** |
| Второй модификатор | **Alt** | **Option ⌥** |
| Третий | **Win ⊞** | **Control ⌃** |
| Усилитель | **Shift** | **Shift ⇧** |

Правило перевода почти всегда простое: **там, где в Windows нажимают Ctrl, на Mac нажимают Cmd**.
`Ctrl + C` → `Cmd + C`, `Ctrl + Z` → `Cmd + Z`. Исключения есть (о них ниже), но 90% сочетаний
переводятся именно так.

## Базовый набор: работает везде

Эти сочетания одинаково работают в тексте, таблицах, почте и браузере:

| Действие | Windows | macOS |
| --- | --- | --- |
| Копировать | `Ctrl + C` | `Cmd + C` |
| Вырезать | `Ctrl + X` | `Cmd + X` |
| Вставить | `Ctrl + V` | `Cmd + V` |
| Отменить | `Ctrl + Z` | `Cmd + Z` |
| Вернуть отменённое | `Ctrl + Y` | `Cmd + Shift + Z` |
| Выделить всё | `Ctrl + A` | `Cmd + A` |
| Сохранить | `Ctrl + S` | `Cmd + S` |
| Найти | `Ctrl + F` | `Cmd + F` |
| Печать | `Ctrl + P` | `Cmd + P` |

<Callout title="Ctrl+Z — кнопка «спасите»">
Отмена работает не только с текстом: она вернёт удалённый файл в проводнике, отменит случайную
сортировку в Excel и неудачную замену в документе. Первое, что стоит нажать, когда «всё сломалось», —
`Ctrl + Z` (на Mac `Cmd + Z`). А «вернуть как было» — `Ctrl + Y` / `Cmd + Shift + Z`.
</Callout>

## Смена языка: сочетание, которое нажимают чаще всех

Русская раскладка ↔ английская — самое частое переключение за день:

| Система | Сочетание |
| --- | --- |
| Windows | `Win + Пробел` (современное) или `Alt + Shift` / `Ctrl + Shift` (классика, зависит от настроек) |
| macOS | `Ctrl + Пробел` или `Cmd + Пробел` (если поиск Spotlight переназначен) |

<Callout title="Печатаете не в то окно и не тем языком?">
Две привычки экономят нервы: 1) на Windows `Win + Пробел` показывает список раскладок на экране —
видно, куда переключились; 2) если напечатали строку не в той раскладке, во многих системах и
приложениях есть переключение регистра/раскладки задним числом (например, Punto-подобные утилиты
или `Shift + Pause` в них) — но надёжнее выработать привычку смотреть на индикатор языка перед
вводом пароля: он не отображается звёздочками, и ошибка раскладки — главная причина «неверный пароль».
</Callout>

## Окна и рабочие столы: где живёт многозадачность

Настоящая экономия времени начинается на уровне операционной системы.

**Переключение между окнами:**

| Действие | Windows | macOS |
| --- | --- | --- |
| Следующее окно | `Alt + Tab` (держим Alt — видим карусель) | `Cmd + Tab` (между программами) |
| Окна одной программы | — | `` Cmd + ` `` (клавиша над Tab) |
| Свернуть окно | `Win + Стрелка вниз` | `Cmd + M` |
| Закрыть окно | `Alt + F4` | `Cmd + W` (окно) / `Cmd + Q` (вся программа) |
| Прилепить окно к половине экрана | `Win + Стрелка влево/вправо` | зажать зелёную кнопку окна → выбрать половину |
| Показать рабочий стол | `Win + D` | `Fn + F11` |

<Callout title="Win+стрелки — «раскладка без мыши»">
Связка для работы с двумя документами: `Win + ←` одному окну, `Win + →` второму — и экран поделён
пополам: слева отчёт, справа таблица с данными. На внешнем мониторе `Win + Shift + стрелка`
перекидывает окно между экранами. Это тот приём, после которого коллеги спрашивают «как ты это сделал?».
</Callout>

**Рабочие столы** (виртуальные): несколько независимых «экранов» — на одном почта и мессенджеры,
на другом — работа с данными. Переключение мгновенное:

| Действие | Windows | macOS |
| --- | --- | --- |
| Создать рабочий стол | `Win + Ctrl + D` | `F3` (Mission Control) → «+» |
| Переключиться между столами | `Win + Ctrl + ←/→` | `Ctrl + ←/→` |
| Обзор всех окон и столов | `Win + Tab` | `F3` |
| Закрыть текущий стол | `Win + Ctrl + F4` | в Mission Control — крестик |

**Системные:**

| Действие | Windows | macOS |
| --- | --- | --- |
| Заблокировать компьютер | `Win + L` | `Ctrl + Cmd + Q` |
| Диспетчер задач / принудительное закрытие | `Ctrl + Shift + Esc` | `Cmd + Option + Esc` |
| Поиск по компьютеру | `Win` (и печатать) | `Cmd + Пробел` (Spotlight) |
| Настройки | `Win + I` | `Cmd + ,` (в любой программе — её настройки) |
| Проводник / Finder | `Win + E` | `Cmd + N` в Finder |

<BusinessNote>
`Win + L` (блокировка) — это не про удобство, а про безопасность: незаблокированный компьютер
с открытой почтой и CRM в офисе или коворкинге — готовый инцидент. Во многих компаниях «отошёл —
заблокируй» закреплено в политике безопасности, и привычка нажимать Win+L спасает от неприятных
разговоров со службой безопасности.
</BusinessNote>

## Скриншоты: доказательство вместо тысячи слов

Скриншот — рабочий инструмент аналитика: зафиксировать ошибку, согласовать макет, сохранить цифры.

| Действие | Windows | macOS |
| --- | --- | --- |
| Скриншот области (в буфер) | `Win + Shift + S` | `Cmd + Shift + 4` |
| Весь экран | `PrtScr` (в буфер) / `Win + PrtScr` (в файл) | `Cmd + Shift + 3` |
| Скриншот окна | `Alt + PrtScr` | `Cmd + Shift + 4`, затем `Пробел` |
| Запись экрана | `Win + Alt + R` (Game Bar) | `Cmd + Shift + 5` |

## Текст: двигаться по документу со скоростью мысли

Второй уровень мастерства — перемещение и выделение без мыши:

| Действие | Windows | macOS |
| --- | --- | --- |
| На слово влево/вправо | `Ctrl + ←/→` | `Option + ←/→` |
| В начало/конец строки | `Home` / `End` | `Cmd + ←/→` |
| В начало/конец документа | `Ctrl + Home/End` | `Cmd + ↑/↓` |
| Выделить слово/строку | добавьте `Shift` к любому перемещению | так же |
| Удалить слово целиком | `Ctrl + Backspace` | `Option + Backspace` |

Заметьте систему: **любое перемещение + Shift = выделение**. Выучили пять перемещений — бесплатно
получили пять способов выделять. `Ctrl + Shift + End` — «выделить всё от курсора до конца документа» —
собирается из этих кубиков сам.

## Браузер и таблицы: рабочие инструменты аналитика

| Действие | Windows | macOS |
| --- | --- | --- |
| Новая вкладка | `Ctrl + T` | `Cmd + T` |
| Закрыть вкладку | `Ctrl + W` | `Cmd + W` |
| **Вернуть закрытую вкладку** | `Ctrl + Shift + T` | `Cmd + Shift + T` |
| Перейти между вкладками | `Ctrl + Tab` / `Ctrl + 1…9` | `Cmd + Option + ←/→` / `Cmd + 1…9` |
| Адресная строка | `Ctrl + L` | `Cmd + L` |
| Обновить страницу | `F5` / `Ctrl + R` | `Cmd + R` |
| Режим инкогнито | `Ctrl + Shift + N` | `Cmd + Shift + N` |

И три сочетания, которые окупают всю лекцию в Excel/Google Sheets (подробнее — в лекции про
таблицы):

- `Ctrl + ↓/→` — прыжок к краю заполненного диапазона (вместо минуты прокрутки);
- `Ctrl + Shift + ↓` — выделить колонку данных до конца;
- `F2` (Win) / `Enter` (Mac) — редактировать ячейку без двойного клика.

## Как это выучить и не бросить

1. **Не учите списками.** Возьмите 3–4 сочетания, которые закрывают ваши самые частые действия,
   и неделю принципиально не делайте их мышью. Потом следующие 3–4.
2. **Подписывайте себе стикер** на монитор с текущей «тройкой недели» — звучит по-школьному,
   работает безотказно.
3. **Подглядывайте в меню.** В любой программе рядом с пунктом меню написано его сочетание —
   это встроенная шпаргалка. Заметили, что жмёте один пункт меню по десять раз в день, — посмотрите
   там же его горячую клавишу.
4. **Тренажёр выше** — прогоните его до 100% пару дней подряд: мышечная память ставится быстрее,
   чем кажется.

## Граничные случаи: где всё ломается

**Alt+Tab отпущен слишком рано.** Если отпустить Alt до того, как выбрали нужное окно в карусели,
переключение произойдёт на первое попавшееся, а не на задуманное. Почему: карусель работает, пока
зажат модификатор — отпускание Alt подтверждает текущий выбор в списке. Правильно: держать Alt,
несколько раз нажать Tab (или Tab с Shift — для движения назад), отпустить только когда нужное окно
подсвечено.

**Ctrl+Z после сохранения и закрытия файла.** Отмена работает только в рамках открытой сессии
редактора и его истории изменений в памяти. Почему: история отмен не пишется на диск вместе с
файлом — она живёт только пока программа открыта. Если файл закрыли или программу перезапустили,
Ctrl+Z отменять уже нечего. Правильно: держать файл открытым, пока не убедились, что правка
корректна, или сразу открыть версию/резервную копию, если она есть.

**Пустое поле ввода при поиске (Ctrl+F).** Нажатие Enter в пустой строке поиска не выдаёт ошибку и
не находит «ничего» — многие программы в этом случае либо ничего не делают, либо повторяют последний
поисковый запрос из истории. Почему: поле без введённого текста не воспринимается как «искать
пустую строку» — это невалидный или неопределённый запрос, и программа откатывается к последнему
известному состоянию. Правильно: всегда вводить хотя бы часть искомого слова перед Enter.

**Одновременное нажатие двух системных сочетаний с общей клавишей.** Например, `Win + L` сразу
после набора `Win + D` — если клавиши перекрываются по времени, система может понять это как одно
смешанное сочетание или проигнорировать второе. Почему: обработчик клавиатуры видит состояние
модификаторов и клавиш в очень коротких временных окнах, и «дребезг» между двумя быстрыми
сочетаниями может слиться в одно событие. Правильно: полностью отпускать все клавиши между двумя
разными сочетаниями, а не тянуть одно в другое.
