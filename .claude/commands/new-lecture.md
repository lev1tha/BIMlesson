---
description: Создать новую лекцию в MDX для одного из четырёх предметов
argument-hint: <subject-slug> <тема лекции>
---

Создай новую лекцию: `$ARGUMENTS`

Первый аргумент — slug предмета (`computer-systems`, `systems-programming`,
`web-development`, `computer-literacy`). Остальное — тема.

Порядок работы:

1. Прочитай `meta.json` предмета и 1–2 соседние лекции, чтобы попасть в
   существующий тон, глубину и уровень сложности. Не изобретай новый стиль.
2. Определи следующий свободный `order`. Имя файла — `NN-kebab-case-slug.mdx`,
   где NN совпадает с order.
3. Напиши лекцию по правилам раздела «Контент: MDX» в CLAUDE.md:
   - валидный frontmatter, `duration` оцени честно по объёму;
   - структура: зачем это нужно → разбор → пример → практика;
   - каждый новый термин объяснён при первом упоминании;
   - три экрана текста подряд без интерактива недопустимы.
4. Подбери интерактив из уже существующих виджетов в `components/widgets/`.
   **Сначала переиспользуй существующий с другими пропсами.** Новый виджет
   создавай, только если ни один не подходит, и скажи об этом явно.
5. Заверши блоком `<Quiz />` на 3–5 вопросов по материалу этой лекции.
   Неправильные варианты должны быть правдоподобными — типичные ошибки студентов,
   а не заведомая чушь.
6. Обнови `meta.json`.

В конце покажи: путь к файлу, какие виджеты использованы, что осталось доделать
руками (схемы, скриншоты, материалы с пары).

Не трогай соседние лекции. Не меняй общие компоненты ради одной страницы.
